CHATBOT MAESTRO PITÁGORAS II - PRIMERA VERSIÓN

Archivos principales:
- index.html: página web principal.
- styles.css: diseño responsive con estilo moderno.
- script.js: lógica del chatbot y base de datos.
- logo.jpg: logo de la unidad educativa.
- chatbot_logo.jpeg: icono del chatbot.
- autores.jpg: imagen de los autores.
- manifest.webmanifest y sw.js: configuración básica tipo app/PWA.

Cómo abrir:
1. Descomprimir el archivo ZIP.
2. Abrir index.html en Google Chrome, Edge o Firefox.
3. Para subir a GitHub Pages, cargar todos estos archivos juntos en la misma carpeta o raíz del repositorio.

Nota de privacidad:
No se incluyeron carnets de identidad, firmas ni imágenes completas de los partes de asistencia porque contienen datos personales. La página sí incluye nombres, cargos, materias y horas de trabajo solicitadas.
